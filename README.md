# MAKK Batas

Catálogo web de batas de baño de MAKK Creaciones: https://batas.ubbedigital.com

Sitio estático en Astro 7 + Tailwind 4. Los clientes ven los modelos, eligen
talla, colores y bordado, y consultan el precio por WhatsApp.

```bash
nvm use 22
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
```

Cómo se carga el catálogo, las reglas de trabajo y el deploy: [AGENTS.md](AGENTS.md).
